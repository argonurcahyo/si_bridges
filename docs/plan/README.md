|---|---|---|
| [`ews-simulator.md`](ews-simulator.md) | Selesai, F0–F6 (19 November 2026) | Dua use case: Early Warning System (operator + warga), Simulator (perencana), dan UI bilingual ID/EN |

## Cara Memakai

- Satu fase = satu sesi kerja dan satu commit/PR.
- Setiap PR menyebut ID requirement dan fase (misal `F1` atau `Q3`).
- Sebelum memulai fase, baca bagian fase terkait dan kriteria selesainya.
- Perbarui tabel status di atas saat fase selesai.
