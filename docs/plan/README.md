# Rencana Pengembangan

Dokumen rencana yang menjadi acuan pengembangan berikutnya.

| Rencana | Status | Cakupan |
|---|---|---|
| [`web-publik.md`](web-publik.md) | Disetujui, siap dikerjakan | Halaman masyarakat: zonasi desa, evakuasi, snapshot publikasi operator, offline |
| [`dashboard.md`](dashboard.md) | Selesai P0–P5, sisa P6 | Dashboard operator: peta 2D/3D, simulasi, grafik, rekomendasi, draf peringatan |

## Cara Memakai

- Satu fase = satu sesi kerja dan satu commit/PR.
- Setiap PR menyebut ID requirement dan fase (misal `Q3`).
- Sebelum memulai fase, baca bagian fase terkait dan kriteria selesainya.
- Perbarui tabel status di atas saat fase selesai.
