# Glosarium

| Istilah | Arti | Catatan |
|---|---|---|
| BMKG | Badan Meteorologi, Klimatologi, dan Geofisika | Sumber data curah hujan dan prakiraan |
| BPBD | Badan Penanggulangan Bencana Daerah | Pengguna utama dashboard |
| C-value (koefisien limpasan) | Proporsi curah hujan yang menjadi limpasan (0–1) | Dipengaruhi tutupan lahan |
| CHIRPS | Climate Hazards Group InfraRed Precipitation with Station data | Data presipitasi grid |
| DAS | Daerah Aliran Sungai | Sub-DAS Ciliwung Hulu–Tengah |
| DEMNAS | Digital Elevation Model Nasional | Dari BIG, resolusi ~8 m |
| Debit (Q) | Volume air per satuan waktu | Satuan m³/s |
| DFD | Data Flow Diagram | Diagram aliran data |
| DSDA | Dinas Sumber Daya Air DKI Jakarta | Pengguna utama dashboard |
| DSS | Decision Support System | Alat bantu keputusan, bukan pengambil keputusan |
| Edge | Segmen sungai yang menghubungkan dua node | Dalam graf hidrologi |
| GEE | Google Earth Engine | Platform citra satelit |
| GeoJSON | Format data geospasial berbasis JSON | Format data peta dashboard |
| Gate | Tahapan pendampingan SI Bridges Indonesia | Gate I sampai V |
| HITL (Human-in-the-Loop) | Manusia memutuskan sebelum aksi | Prinsip utama sistem |
| LLM | Large Language Model | Dipakai untuk narasi rekomendasi |
| LULC | Land Use / Land Cover | Tutupan dan penggunaan lahan |
| MapLibre GL JS | Library peta open source berbasis WebGL | Dipakai untuk prototipe |
| Mode Latihan | Mode dengan data mock | Ditampilkan di banner |
| Node | Titik di graf: pintu air, penampungan, atau sensor | — |
| Rule-based fallback | Narasi dari aturan tetap saat LLM gagal | Jalur darurat |
| Segmen | Unit wilayah (kelurahan) atau bagian sungai | Konteks dipertegas di dokumen |
| SHP | Shapefile | Format data vektor sumber |
| Siaga | Level risiko tertinggi | Warna merah |
| Waspada | Level risiko menengah | Warna kuning |
| Aman | Level risiko rendah | Warna hijau |
| TMA | Tinggi Muka Air | Diukur di pintu air |
| WIB | Waktu Indonesia Barat | Zona waktu semua tampilan |
| WCAG | Web Content Accessibility Guidelines | Acuan aksesibilitas |
